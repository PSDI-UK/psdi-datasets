## Files

This folder contains JSON extracted from the supplementary information of the paper - Towards the Prediction of Antimicrobial Efficacy for Hydrogen Bonded, Self-Associating Amphiphiles (https://doi.org/10.1002/cmdc.202000533). We have extracted the specific section of the ESI we are working with - see towards_supplementary_info_cmc.pdf.
 
We have extracted the image of the Surface Tension vs concentration plot used to calculate critical micelle concentrate (CMC) and JSON files are saved in folders relating to the molecule ID from the paper with the images and JSON file.
 
The JSON files contain information on the molecule, its identifiers, the coordinates extracted from the plot and the original line of best fit from the ESI. The JSON file was extracted using methods outlined in the report (insert report info before publication) with definition referenced to anthologies where the terms are available, see ontology_references_and_definitions.csv file.
 
We also have the .ipynb files used to curate and re-plot the JSON files.
